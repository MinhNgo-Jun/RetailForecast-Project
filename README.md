### RetailForecast-Project
##### The data are monthly measures of retail trade volume in Australia, obtained from the ABS - Furniture, Floor Coverings, Houseware, and Textile Goods Retailing. STL decomposition, ETS and ARIMA models are used to get some significant insights of dataset. 
##### Main tasks are:
##### - Decide which model is appropriate for the data by comparing these results based on AICc, RMSE, and residuals
##### - Apply the best performance model to forecast the predictions in the next several months.
